# Лабораторная работа №2: Обучение однослойного перцептрона

## Описание проекта
Этот проект представляет собой реализацию однослойного перцептрона для задачи бинарной классификации (предсказание дефолта по кредитным данным). Проект выполнен с использованием только базовых математических операций, без применения готовых библиотек для машинного обучения, таких как TensorFlow или PyTorch.

## Цели
- Реализовать обучение перцептрона с нуля.
- Достичь точности не менее 85% на тестовой выборке.
- Обеспечить работу с большим объемом данных (1 млн примеров).

## Структура проекта
1. **Генерация данных**:
   - Скрипт генерирует синтетические кредитные данные с 30 признаками, включая возраст, доход, кредитную историю и другие.
   - Данные нормализуются и сохраняются в файл `credit_data_1m.csv`.

2. **Обучение модели**:
   - Реализован однослойный перцептрон с сигмоидной функцией активации.
   - Используется функция потерь (кросс-энтропия) и градиентный спуск для оптимизации.
   - Модель обучается на 70 000 примерах, валидируется на 15 000 и тестируется на 15 000.

3. **Оценка результатов**:
   - Вычисляются метрики: точность, precision и recall.
   - Результаты сохраняются в файл `w&b.txt`.

## Требования
- Python 3.x
- Библиотеки: `numpy`, `pandas`

## Результаты 
- Test Accuracy: 0.8993
- Test Precision: 0.7839
- Test Recall: 0.6491
